# GYM

Дневник весов по группам мышц, перенесённый из Apple Notes. Одна HTML-страница без сборки и зависимостей.

Открыть: https://hovo92000.github.io/gym/

На iPhone: Safari → Поделиться → «На экран Домой». Данные хранятся в браузере устройства; резервная копия — вкладка «Заметки» → «Скачать файл».
